# PEER TO PEER — application starter

This is the first frontend foundation for PEER TO PEER.

## Included
- Next.js App Router
- TypeScript
- Tailwind CSS (v4)
- Responsive landing page
- Basic brand styling and page metadata

## Requirements
- Node.js (current LTS recommended)
- npm

## Run locally or in GitHub Codespaces

```bash
npm install
npm run dev
```

Open the forwarded port shown by Codespaces (usually port 3000).

## Important
- This is a frontend starter, not the complete platform.
- Supabase has not yet been connected.
- Authentication, mentor onboarding, marketplace, messaging, payments, payouts, moderation and admin tools will be added in later stages.
- Do not commit `.env` files, passwords, Supabase service-role keys, or other secrets.
- The email links on the landing page are placeholders and must be replaced before launch.
